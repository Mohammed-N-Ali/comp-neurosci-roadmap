# <u>Computational Neuroscience Roadmap</u>

This repositiory has been created to track my progress as I read through various books, complete multiple courses, and apply the knowledge I learn to real-life projects that directly link to the brain, weaving in mathermatics, biology, programming and signal processing. 

## _Phases:_
---

* _Phase 0: Programming Foundations_ 
    - Here, I will learn the basics of programming, specifically in python
* _Phase 1: Mathematics_
     - Here, I wiil learn mathematic principles and linear algebra to be able to apply them to a scientific computing environment
* _Phase 2: Scientific Python_
    - Here, I will combine Phase 0 + Phase 1, applying mathematical knowledge and scientific data to python
* _Phase 3: Computational Neuroscience_
     - Here, I will learn the basics of applying biological data to scientific python, learning the mathematical modelling behind neurons and networks
* _Phase 4: Neural Data Analysis_
    - Here, I will learn to analyse and decode information from real recordings using signal processing and ML
* _Phase 5: Systems Engineering_ 
    - Here, I will learn low level programming and how to build fast scientific software in python and C++
* _Phase 6: Julia and Theoretical Neuroscience_ 
    - Here, I will learn high-performance scientific computing and discover advanced mathematical theories behind the brains inner functions
