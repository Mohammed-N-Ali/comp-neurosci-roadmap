# <u> Chapter 1 Notes</u>

Expression = A combination of values and operators that reduce down to a single values

<b>Operators:</b>
* ** = Exponentiation
* % = Modulus/Remainder
* // = Integer division(Same result as regular division but rounded down)
* / = Division
* '*' = Multiplication
* '-' = Subtraction
* '+' = Addition

Precedence = Order of operations - Can use brackets to alter this
<br>**, *, /, //, %, +, -

Syntax error = Wrong grammar

## Data types
---
- Integer(int) = Whole number
- Float(float) = Number with decimal
- String(str) = Text

Any expression formed using an integer and a float = float.

Any division between 2 integers also = float.

Some operators will not work on certain combinations of data types, for example, adding a string and int : multiplying string and integer rrsults in string replication, causing the string to repeat the same amount of times as the int multiplied

## Variable
---
Variable = Box where you can store single value using assingment operator (=)

Overwriting Variable = Replacing Value in Box

Variable = Case sensitive

## Different Functions
---
- print() = Displays string/variable inside parentheses
- input() = Text inputted by user to be used in program : Can have a prompt inside brackets with string ''
- len() = Integer value of number of values in that string
- str() = Changes data type to string
- int() = Changes data type to integer
- float() = Changes data type to float
- type() = Determines what daya type 
- round() = Accepts float valuse and returns nearest integer : can use comma and add how many decimal places. Half numbers, aka 2.5,3.5,etc, are rounded to the nearest even integer
- abs() = Returns absolute value
