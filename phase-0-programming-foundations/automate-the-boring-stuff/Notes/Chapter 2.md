# <u>Chapter 2 Notes</u>

Flow control statements = Decide which Python instructions to execute under which conditions

## Boolean Values
---
Boolean = Data type wuth only two values : True and False

You can use Boolean values in expressions and store them in variables.

## Comparison operators
---
* ==  : Equal to
* ! = : Not equal to
* <   : Less than
* '>' : Greater than
* <=  : Less than or equal to
* '>=' : Greater than or equal to

== & != can work with any data types wheres <,>,<=,>= only work with integers and float

## Boolean operators
---
3 Boolean operators:
*And - All expressions must be True to return True, otherwise False
*Not - Changes True to False and vice versa
*Or - One or more expressions must be True too return True, otherwise False

## Combining Boolean and Comparison operators
---
Computer will evaluate expressions, simplifying them down to Boolean values and companing them using Boolean operators

## Flow Control Statements
---
* if - Executes indented code if statements condition is True
* else - Executes when the if statements condition is False - does not have its own condition
* elif - Executes if another condition is met only if all the previous conditions were false
